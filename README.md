# Face Detector Using OpenCV

## Project Description
A Python project that detects faces in images using OpenCV and the Haar Cascade classifier.

## Features
- Detects multiple faces
- Draws green rectangles around faces
- Counts detected faces
- Saves the output image

## Technologies
- Python
- OpenCV
- Haar Cascade Classifier

## Installation
Run `python -m pip install -r requirements.txt`

## How to Run
Run `python face_detector.py` and enter your image filename.

## Output
The detected image is saved as `detected_faces.jpg`.
